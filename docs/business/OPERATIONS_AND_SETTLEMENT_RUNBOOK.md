## 2. 거래 라이프사이클 7단계 운영 지침

```text
[1. 고객 신청] -> [2. 1:1 독점 오퍼 (15분)] -> [3. 파트너 수락 & 연락처 인계]
                                                        │
[7. 월말 35% 리퍼럴 정산] <- [6. 8% 수수료 입금] <- [5. 고객 승인] <- [4. 시공 & 2장 사진]
```

### 단계 1: 고객 신청 접수 (`POST /inquiries`)
- 고객이 법정 필수 동의 2건을 체크하고 신청서 제출.
- 전화번호는 HMAC-SHA256 해시로 D1에 비식별화 저장, AES-256-GCM 암호화 보관.

### 단계 2: 1:1 독점 오퍼 발송 (`assignment_offers`)
- 결정적 매칭 알고리즘이 관악/동작 권역 승인 파트너 중 1순위를 선별해 15분 독점 오퍼 발급.
- 해당 파트너의 슬롯은 `OFFERED` 상태로 잠겨 타 고객과 중복 배정 방지.
- 15분 초과 시 `processTimeoutsInternal`에 의해 오퍼 `EXPIRED`, 슬롯 `AVAILABLE` 원복 후 2순위 자동 재배정.

### 단계 3: 파트너 오퍼 수락 (`POST /offers/:id/accept`)
- 파트너가 모바일 대기함(`partner-slots.html`)에서 오퍼 수락.
- 수락 즉시 고객 성명/연락처가 복호화되어 파트너 화면 모달에 일회 안전 공개 (`PII_HANDOFF` 감사 로그 자동 적재).
- 파트너가 고객에게 유선 연락하여 세부 방문 시간 및 현장 특이사항 조율.

### 단계 4: 시공 완료 및 2장 사진 증빙 (`POST /matches/:id/fulfill`)
- 시공 완료 후 파트너가 현장 사진 2장 이상(배수구, 가스레인지/환풍기 등 필수 탈거 구역)을 등록.
- 2장 미만 또는 유효하지 않은 사진 등록 시 시스템이 400 에러로 완료 처리 거부.
- 상태가 `COMPLETED`로 변경되나, 고객 승인 전까지는 회계상 매출로 잡히지 않음 (과대계상 방지).

### 단계 5: 고객 완료 확인 (`POST /matches/:id/confirm`)
- 고객이 시공 사진 확인 후 승인 버튼 클릭 (또는 만족도 평가 5점).
- 매칭 상태가 정식 청구 가능 상태인 `BILLABLE` 또는 `VERIFIED`로 최종 전이.
- 고객은 현장에서 파트너에게 시공 대금(약 20~25만 원)을 계좌이체 또는 현금으로 100% 직접 지급.

### 단계 6: 플랫폼 8% 수수료 청구 및 입금 분개 (`admin-billing.html`)
- 관리자가 청구서 발행 버튼 클릭 (`POST /admin/invoices/generate`).
- 파트너에게 8% 수수료 입금 계좌 안내 (예: 25만 원 시공 시 20,000원).
- 은행 입금 확인 후 거래 적요(4자 이상)를 입력하고 `[입금 확인 및 원장 분개]` 실행.
- D1 `env.DB.batch`로 인보이스 `PAID` 전환, 현금 계정 차변/대변 복식부기 기재, 감사 로그가 원자적으로 저장됨.

### 단계 7: 유입 제휴사 리퍼럴 35% 정산 (`POST /admin/payouts/:id/approve`)
- 유입 경로가 중개사/위젯인 경우 플랫폼 수익의 35%(건당 7,000원) 리퍼럴 정산금 발생.
- 관리자가 증빙 ID(세금계산서 또는 지급 영수증 번호)를 입력하고 승인 처리.

## 3. 3대 비상 상황(Dispute) 분쟁 중재 스크립트

### 3.1 파트너 노쇼(No-Show) 또는 당일 지각
- **상황:** 파트너가 약속 시간에 나타나지 않거나 연락 두절된 경우.
- **조치 절차:**
  1. 즉시 2순위 대기 파트너에게 긴급 콜 연결 및 대체 출동 가능 여부 타진.
  2. 고객에게 즉시 전화하여 정중히 사과 후 대체팀 투입 안내 (불가 시 즉시 취소).
  3. 노쇼 파트너는 즉시 영구 자격 박탈 (`verification_status = 'SUSPENDED'`) 및 위약벌 10만 원 고지.

### 3.2 현장 부당 추가금 요구 분쟁
- **상황:** 파트너가 현장에서 '오염이 심하다'며 과도한 추가금(5~10만 원)을 요구하여 고객이 항의하는 경우.
- **조치 절차:**
  1. 파트너에게 오염 부위 실시간 사진 전송 요구.
  2. 통상적인 생활 오염(일반 기름때, 창틀 먼지)인 경우 파트너에게 사전 고지 원칙 상기시키며 추가금 철회 중재.
  3. 명백한 특수 오염(니코틴 도배, 쓰레기집, 반려동물 분변)인 경우에만 고객 사전 동의 하에 2~3만 원 범위 내 실비 조정.
  4. 파트너가 막무가내 추가금 요구 시 즉시 파트너 제휴 타절 경고.

### 3.3 시공 후 청소 불만족 및 하자 클레임
- **상황:** 청소 완료 후 고객이 특정 부위(창틀, 수전, 싱크대 하부 등) 오염 잔존을 지적하는 경우.
- **조치 절차:**
  1. 24시간 이내 무상 재청소 A/S 규약에 따라 해당 시공팀에게 당일 또는 익일 오전 재방문 A/S 지시.
  2. 시공팀이 재청소를 거부하거나 회피할 경우, 해당 건 수수료 청구 전액 면제 및 타 파트너 투입 보상.
  3. 고객 평점 3점 미만 3회 누적 시 파트너 자동 제명.
