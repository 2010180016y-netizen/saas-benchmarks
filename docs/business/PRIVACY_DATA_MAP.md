## 1. 개인정보 수집 및 처리 원칙 (Data Minimization)

SlotBridge Korea는 개인정보 보호법 제3조(개인정보 보호 원칙) 및 제16조(수집 제한)에 따라, 24~72시간 급행 입주·이사청소 중개 서비스 제공에 **필수적인 최소한의 정보만을 수집**한다.

### 1.1 처리 대상 데이터 항목 구분

| 구분 | 수집 항목 | 수집 목적 | 수집 시점 | 필수/선택 |
|---|---|---|---|---|
| **기본 연락처** | 성명, 휴대전화번호 | 고객 본인 식별, 매칭 상태 알림 및 수락업체 1:1 연결 | 인입 폼 제출 시 | **필수** |
| **청소 작업 조건** | 희망 일시(24~72h 이내), 주소(시/군/구, 읍/면/동) | 작업 권역 및 가용 슬롯 매칭 판정 | 인입 폼 제출 시 | **필수** |
| **공간 상세 조건** | 주거 형태(원룸/투룸/오피스텔/아파트), 전용면적(평/㎡), 엘리베이터 유무 | 예상 작업량 및 소요시간 산정 | 인입 폼 제출 시 | **필수** |
| **추가 작업 요청** | 베란다/창틀/곰팡이/가전 내부 청소 선택 여부 | 현장 추가비용 방지 및 맞춤 장비 준비 | 인입 폼 제출 시 | 선택 |
| **기기/접속 로그** | 접속 IP, 접속 일시, User-Agent, 유입 식별자(`ref_id`) | 부정 이용 방지, 통계, 원 유입업체 리퍼럴 추적 | HTTP 요청 시 | 자동 수집 |

### 1.2 [수집 절대 금지 항목 (Prohibited Data)]
1. **주민등록번호, 여권번호 등 고유식별정보:** 일체 수집하지 않음.
2. **상세 동·호수:** 인입 단계에서는 절대 수집하지 않음. (동·호수 등 민감한 거주지 상세 정보는 매칭이 확정된 후, 고객과 수락업체가 유선으로 최종 일정을 확정하는 단계에서 수락업체가 직접 수령).
3. **신용카드 번호, 계좌번호 등 금융 결제 정보:** 플랫폼이 결제대금을 수취하지 않으므로 일체 수집하지 않음.
4. **실내 현장 사진:** 거주자 사생활 및 개인 식별물(가족사진, 문서 등) 노출 위험 방지를 위해 초기 인입 단계에서는 수집하지 않음.

## 2. 원 유입업체 임의 대리 입력 원천 차단 아키텍처

- **[LEGAL_RISK]** 원 유입업체(제휴 청소업체)가 자사로 걸려온 고객 전화번호나 상담 내역을 임의로 엑셀 파일로 취합하여 플랫폼에 일괄 업로드하거나 대리 입력하는 행위는 **개인정보 보호법 제15조 및 제17조 위반(불법 제3자 제공)**에 해당한다.
- **차단 메커니즘 (Technical Guardrail):**
  1. **배치 업로드 API 금지:** 시스템 내 대량 엑셀/CSV 업로드 엔드포인트를 구현하지 않는다.
  2. **전용 리퍼럴 URL 강제:** 원 유입업체는 자사 일정 마감 시, 고객에게 고유 파라미터가 포함된 웹 링크(예: `https://.../inquiry?ref=PARTNER_A102`)를 문자로 안내한다.
  3. **고객 직접 서명/동의 필수:** 해당 웹페이지에 최종 고객이 본인의 단말기로 직접 접속하여, 법정 고지문을 육안으로 확인하고 직접 체크박스를 선택한 후 제출해야만 데이터가 인입된다.

## 3. 데이터 라이프사이클 및 보안 통제 (Data Lifecycle Security)

```
[인입 단계]                    [저장 단계]                   [매칭/전송 단계]               [파기 단계]
고객 직접 입력 (TLS 1.3)   ->   AES-256-GCM 암호화 저장   ->   1:1 배타적 전송 (단 1개 업체) ->   30일 후 PII 영구 파기
(시군구/동만 수집)              (Cloudflare D1 SQLite)        (동의 없는 N개 입찰 금지)       (로그 마스킹 / 익명화)
```

### 3.1 저장 및 암호화 (Data-at-Rest)
- **저장소:** Cloudflare D1 (분산 SQLite 데이터베이스).
- **필드 레벨 암호화 (Application-Level Encryption):**
  - 성명 및 휴대전화번호는 데이터베이스 저장 전, Cloudflare Worker 환경에서 Web Crypto API(`AES-GCM-256`)를 통해 암호화되어 바이트 배열로 저장된다.
  - 암호화 키는 Worker Secret(`ENCRYPTION_KEY`)으로 안전하게 주입되며, GitHub 소스코드나 설정 파일에 절대 노출되지 않는다.
- **데이터베이스 접근 통제:** 관리자 인터페이스는 Cloudflare Zero Trust(Access) 기반의 2단계 인증(2FA)을 통해서만 접근 가능하다.

### 3.2 전송 및 제공 통제 (Data-in-Transit & Sharing)
- **HTTPS 강제:** 모든 웹 트래픽 및 API 호출은 TLS 1.3으로 보호된다.
- **[핵심 원칙] 1:1 배타적 전달 (No Open Broadcast):**
  - 고객의 개인정보를 불특정 다수의 청소업체에 경매식으로 열어놓고 열람하게 하는 '리드 판매' 방식은 전면 금지된다.
  - 매칭 엔진이 가용 슬롯과 평점을 기준으로 선정한 **단 1개의 정식 승인 공급업체**에게만 수락 기회가 주어지며, 해당 업체가 15분 내 수락한 경우에만 해당 업체 관리자 포털에 복호화된 연락처가 일시 노출된다.

### 3.3 보관 기간 및 파기 정책 (Retention & Destruction)

| 데이터 유형 | 보관 기간 | 파기 시점 및 방법 |
|---|---|---|
| **매칭 실패 / 미수락 건** | 최대 24시간 | 접수 후 24시간 이내 매칭 불발 시 즉시 DB 행 영구 삭제 (`DELETE`) |
| **고객 직접 동의 철회 건** | 즉시 | 철회 요청 즉시 PII 암호화 데이터 복구 불가능하게 덮어쓰기 파기 |
| **매칭 성공 / 완료 건** | 서비스 완료 후 30일 | 청소 완료 보고일로부터 30일 경과 시 성명·연락처 영구 파기 |
| **법정 거래 기록 (거래 증빙)** | 5년 | 전자상거래법 제6조에 따라 계약·정산 메타데이터(고객식별자 익명 해시, 거래일시, 수수료액)만 5년 보존 (PII 제외) |

## 4. 정보주체 권리 행사 및 침해사고 대응

### 4.1 0원 아키텍처 기반 권리 행사 (Self-Service Privacy)
- 고객은 신청 완료 시 화면에 제공되는 고유 URL(예: `/inquiry/status?token=uuidv4`)을 통해 언제든지 본인의 신청 정보를 실시간으로 확인하고, **[신청 취소 및 개인정보 즉시 삭제]** 버튼을 1-Click으로 실행할 수 있다.
- 삭제 요청 시 Worker API는 해당 레코드의 PII 필드를 난수로 덮어쓴 후 삭제(`TOMBSTONE` 상태 전환)하며, 감사 로그(`audit_log`)에 삭제 사유를 기록한다.

### 4.2 개인정보 유출 및 침해사고 대응 프로토콜
1. **사고 인지:** 이상 트래픽 발생, API 비정상 호출, 데이터 탈취 시도 포착.
2. **즉각 격리 (15분 이내):** Cloudflare Worker 방화벽 규칙 적용 및 침해 엔드포인트 차단. 암호화 키 즉시 회전.
3. **법정 신고 (72시간 이내):** 개인정보 유출 사실 확인 시 72시간 이내에 개인정보보호위원회 또는 한국인터넷진흥원(KISA)에 신고.
4. **정보주체 통지:** 유출된 개인정보 항목, 유출 시점, 피해 최소화 조치 방법, 플랫폼 대응 경과를 해당 고객에게 개별 문자/안내 페이지를 통해 지체 없이 통지.
