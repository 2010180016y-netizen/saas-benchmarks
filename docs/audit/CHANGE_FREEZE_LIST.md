- **대상 파일:**

  - `benchmarks/*.html` (Perplexity vs ChatGPT, Claude vs GPT, Cursor vs Copilot 등 벤치마크 3종)

  - `images/*` (기존 인포그래픽 및 브랜드 에셋)
- **동결 사유:** 기존 회기님의 사이트 트래픽 및 제휴 수익 파이프라인 자산이며, SlotBridge 사업과 물리적으로 분리 보존되어야 함. 단 1줄의 수정도 절대 금지.

### 1.2 SlotBridge 프론트엔드 모바일 디자인 & CSS (외형 동결)
- **대상 파일:**
  - `slotbridge/*.html` 및 인라인 `<style>` 테마 변수 (`--bg`, `--card`, `--primary`, `--accent` 등)
  - 모바일 반응형 그리드, 폼 컨트롤, 라디오 필, 탭 바, 어코디언 UI 디자인
- **동결 사유:** 이미 모바일 사용성에 맞추어 고도화된 레이아웃이며, 이번 결함 수정(FIX-01~10)은 **데이터 연동 및 백엔드 바인딩**에 한정됨. 디자인 리뉴얼이나 CSS 재작성 금지.

### 1.3 검증된 도메인 비즈니스 규칙 및 수학적 공식 (로직 동결)
- **대상 로직:**
  - **1:1 배타적 독점 매칭 원칙:** 1개 요청에 다수 업체를 동시 경쟁시키지 않고, 1순위 업체 1곳에만 독점 오퍼 발송.
  - **15분 타임아웃 SLA 정책:** 15분 내 미응답 시 차순위 업체로 자동 순차 재배정.
  - **8% 성과 수수료 모델:** 고객 현장 대금 수취 후 성과 발생 시에만 8%(VAT 별도) 플랫폼 수수료 부과.
  - **35% 리퍼럴 정산 배분:** 원 유입 파트너에게 플랫폼 수취 수수료의 35%(건당 약 7,000원) 무위험 배분.
  - **복식부기 원장 계정과목:** 미수금(111), 현금(101), 수수료매출(401), 부가세예수금(211), 리퍼럴지급채무(212) 5대 표준 분개 구조.
- **동결 사유:** 비즈니스 모델의 근간이자 단위경제성 성립의 핵심 가설이므로 수정 금지.

### 1.4 기존 81개 회귀 테스트 케이스 (베이스라인 보존)
- **대상 파일:** `tests/test_*.py`
- **동결 사유:** 기존 기능의 단위 동작을 검증하는 안전장치이므로, 기존 테스트를 삭제하거나 임의로 수정하여 통과시키는 행위를 금지함. 신규 결함 수정 시 회귀 방지용으로 전원 유지.

## 2. 엄격한 비즈니스 경계 (Scope Boundaries)

1. **지리적 경계 (Geographic Boundary):**
   - 대한민국 서울특별시 **관악구 및 동작구** 단일 권역으로 엄격히 한정.
   - 타 자치구(서초, 강남, 영등포 등) 또는 타 시/도 확장 절대 금지.
2. **품목 경계 (Category Boundary):**
   - **24~72시간 내 급행 원룸·오피스텔 입주/이사청소** 1개 카테고리 한정.
   - 포장이사, 정기 가사도우미, 에어컨 청소, 인테리어 시공 등 타 업종 확장 절대 금지.
3. **인프라 비용 경계 (Cost Ceiling Boundary):**
   - Cloudflare Workers Free Tier + Cloudflare D1 Free Tier 한도 내 $0.00 고정비 유지.
   - 유료 외부 SaaS(유료 DB, 유료 알림톡 API 등) 무단 도입 금지.
