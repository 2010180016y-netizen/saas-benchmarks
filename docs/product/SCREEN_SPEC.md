# SlotBridge Korea — 화면 UI/UX 명세서 (SCREEN_SPEC.md)

**문서 버전:** 1.0.0  
**작성일자:** 2026-10-31  
**디자인 시스템:** Mobile-First Vanilla CSS (Tailwind/Bootstrap 의존성 제로, 번들 크기 < 25KB)  
**기본 경로:** `/slotbridge/*` (기존 SaaS 비교 정적 사이트 자산과 완전 분리 공존)  

---

## 1. 사이트 라우팅 맵 (Routing Architecture)

| 경로 (URL) | 화면 명칭 | 대상 사용자 | 핵심 기능 |
|---|---|---|---|
| `/slotbridge/` | 랜딩 및 가용성 진단 | 일반 방문자 / 고객 | 24~72h 급행 가능 여부 조회, 가이드 |
| `/slotbridge/inquiry` | 고객 신청 및 법정 동의 | 최종 고객 | 조건 입력, 개보법 제17조 동의, 제출 |
| `/slotbridge/status` | 신청 추적 및 1-Click 철회 | 최종 고객 | 매칭 상태 실시간 조회, 동의 즉시 철회/삭제 |
| `/slotbridge/widget.js` | 임베디드 제휴 위젯 스크립트 | 원 유입 파트너 | 타사 웹사이트 내 오버플로우 배너/모달 렌더링 |
| `/slotbridge/partner/slots` | 잔여 슬롯 및 오퍼 관리 | 수행 파트너 | 빈 일정 등록, 15분 독점 오퍼 수락/거절 |
| `/slotbridge/partner/dashboard` | 리퍼럴 기여도 대시보드 | 원 유입 파트너 | 인입/매칭/완료 건수 및 정산액 확인 |
| `/slotbridge/admin/dashboard` | 무인 운영 관제 포털 | 플랫폼 관리자 (회기님) | 파트너 승인, 매칭 큐 모니터링, 월말 세무 집계 |

## 2. 화면별 세부 와이어프레임 및 컴포넌트 명세

### 2.1 [Screen 1] 고객 신청 및 법정 동의 폼 (`/slotbridge/inquiry`)

- **타깃 디바이스:** 모바일 웹 (375px ~ 430px 너비 최적화)
- **레이아웃 구조:**
  ```text
  +-----------------------------------------------+
  | [SlotBridge Korea]       급행 24~72h 매칭      |
  +-----------------------------------------------+
  | [헤더] 서울 관악·동작구 급행 입주·이사청소        |
  |        버려지는 빈 일정을 연결해 드립니다.      |
  +-----------------------------------------------+
  | 1. 청소 희망 일시 (24~72시간 이내만 선택 가능)   |
  |    [ 2026-11-02 (월) ] [ 오전 09:00 ~ 11:00 v ]|
  +-----------------------------------------------+
  | 2. 서비스 지역                                |
  |    [ 서울시 v ] [ 관악구 v ] [ 봉천동 v ]       |
  |    * 상세 주소(동·호수)는 매칭 확정 후 확인     |
  +-----------------------------------------------+
  | 3. 공간 정보                                  |
  |    주거형태: (o) 원룸  ( ) 투룸/오피스텔  ( ) 아파트|
  |    전용면적: [ 8 ] 평 / [ 26.4 ] ㎡           |
  |    추가선택: [v] 베란다  [ ] 가전내부  [ ] 곰팡이|
  +-----------------------------------------------+
  | 4. 신청자 연락처 (필수)                        |
  |    성명:   [ 김관악             ]              |
  |    연락처: [ 010-1234-5678      ]              |
  +-----------------------------------------------+
  | [법정 필수 동의 영역]                         |
  | [ ] (필수) 개인정보 수집 및 이용 동의 [보기]    |
  | [ ] (필수) 개인정보 제3자 제공 동의 (1곳 배타적)|

  +-----------------------------------------------+
  | [ 버튼: 24~72h 급행 슬롯 매칭 신청하기 ]      |
  +-----------------------------------------------+
  ```

### 2.2 [Screen 2] 고객 신청 추적 및 1-Click 철회 (`/slotbridge/status?token=...`)

- **접근 통제:** UUID v4 난수 토큰 기반의 1회성 웹 세션 (비회원 0원 아키텍처)
- **레이아웃 구조:**
  ```text
  +-----------------------------------------------+
  | [신청 접수 현황]       상태: [매칭 진행 중...]  |
  +-----------------------------------------------+
  | • 접수 번호: inq_7a23c59e                     |
  | • 희망 일시: 2026-11-02 오전 10:00            |
  | • 지역/면적: 서울 관악구 봉천동 / 원룸 8평     |
  | • 배정 현황: 관내 검증 청소팀에 오퍼 전송 완료  |
  |             (수락 시 담당 팀장님이 직접 연락) |
  +-----------------------------------------------+
  | [정보주체 권리 행사 버튼]                     |
  | [!] 이사 일정이 변경되셨거나 다른 곳을 찾으셨나요?|
  |                                               |
  | [ 버튼: 신청 취소 및 개인정보 즉시 영구 파기 ]  |
  | * 클릭 시 즉시 매칭이 중단되며 연락처가 삭제됨. |
  +-----------------------------------------------+
  ```

### 2.3 [Screen 3] 원 유입 파트너 임베디드 위젯 (`widget.js`)

- **동작 방식:** 제휴 청소업체 웹사이트의 상담 마감 안내 레이어에 스크립트 1줄로 삽입.
- **코드 예시:**
  ```html
  <script src="https://saas-benchmarks.pages.dev/slotbridge/widget.js" 
          data-partner="cleanhome_gw" 
          data-theme="dark"></script>
  ```
- **화면 UI 렌더링:**
  ```text
  +-----------------------------------------------+
  | ⚠️ 현재 [클린홈]의 24~72시간 일정은 마감되었습니다.|
  |                                               |
  | 관내 공인 연합 청소팀의 [빈 슬롯]을 조회하여     |
  | 급행 예약을 바로 연결해 드릴까요?              |
  |                                               |
  | [ 관악·동작 잔여 급행 슬롯 조회하기 (무료) -> ]|
  +-----------------------------------------------+
  ```
