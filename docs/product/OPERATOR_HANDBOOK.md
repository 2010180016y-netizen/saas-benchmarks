**문서 버전:** 1.0.0  
**작성일자:** 2026-10-31  
**운영 주체:** 김회기 대표 1인 운영체제  
**적용 대상:** `slotbridge/` 웹 콘솔, 관리자 청구 대시보드(`admin-billing.html`), Cloudflare Workers

## 1. 운영 철학 및 99% 자동화 원칙

SlotBridge Korea는 고객 인입, 24~72시간 가용성 검증, 1순위 독점 오퍼 발송, 15분 타임아웃 차순위 재배정, 복식부기 원장 분개, 월간 B2B 인보이스 초안 생성을 **서버리스 코드가 100% 무인 수행**합니다.  
대표님(회기님)은 법적 증빙 검토 및 최종 자금 이체 승인 등 **인간의 의사결정이 필수적인 지점(Human-in-the-Loop)에만 일일 10분, 월간 20분 개입**합니다.

## 2. 일일 10분 운영 루틴 (Daily 10-Min SOP)

```
[09:00 파트너 심사: 3분] ──▶ [14:00 타임아웃 모니터링: 2분] ──▶ [18:00 시공 검수 및 분쟁: 5분]
```

### 2.1 [09:00] 신규 공급자 서류 심사 (3분)
1. `admin-billing.html` 또는 관리자 화면 접속.
2. `PENDING_APPROVAL` 상태의 파트너 신청 내역 확인:
   - 홈택스 사업자등록상태조회(무료)로 휴·폐업 여부 확인 (30초).
   - 영업배상책임보험 증권 번호 기재 확인 (30초).
3. [승인] 버튼 클릭 -> 파트너에게 즉시 슬롯 등록 권한 부여.

### 2.2 [14:00] 미응답 오퍼 및 슬롯 유동성 점검 (2분)
1. `growth-dashboard.html`에서 금일 타임아웃 발생 건수 확인.
2. 15분 미수락 건은 시스템이 차순위로 자동 재배정하므로 개입 불필요.
3. 동일 파트너가 3회 연속 무응답(TIMEOUT) 시 일시 정지(`SUSPEND`) 검토.

### 2.3 [18:00] 시공 사진 검수 및 분쟁 처리 (5분)
1. 당일 완료(`COMPLETED`) 보고된 시공 건의 작업 전·후 사진 2장 육안 확인.
2. 이상 없을 시 [검수 완료(VERIFY)] 승인 -> 복식부기 원장 자동 분개.
3. 고객 불만 접수 건 발생 시:
   - **경미 하자:** 청소팀에 24시간 내 무상 재방문 A/S 지시 ([A/S 지정] 클릭).
   - **중대 과실/불만:** [100% 환불] 승인 -> 원장 자동 역분개 적재.

## 3. 월간 20분 정산 및 세무 루틴 (Monthly 20-Min SOP)

```
[매월 05일] 세금계산서 발행 (10분) ──▶ [매월 10일] 입금 확인 (3분) ──▶ [매월 15일] 리퍼럴 송금 (7분)
```

### 3.1 [매월 05일] B2B 인보이스 발행 및 세금계산서 발급 (10분)
1. 매월 말일 24:00에 시스템이 자동 생성한 당월 청구서 초안(`DRAFT`) 목록 열람.
2. 업체별 검증 완료 건수 및 8% 수수료(+10% VAT) 확인.
3. 홈택스(`hometax.go.kr`)에서 해당 시공업체 사업자번호로 전자세금계산서 발급.
4. 관리자 화면에서 세금계산서 승인번호 입력 후 [청구서 발행(ISSUE)] 클릭 -> 상태 `ISSUED` 전이.

### 3.2 [매월 10일] 수수료 입금 대사 (3분)
1. 법인/개인 통장으로 시공 파트너의 수수료 입금 내역 확인.
2. 관리자 화면에서 [입금 확인(PAID)] 클릭 -> 미수채권 회수 종결.

### 3.3 [매월 15일] 원 유입업체 리퍼럴 35% 송금 (7분)
1. 리퍼럴 파트너(원 유입업체)의 정산 대기열(`PENDING`) 확인.
2. **필수 게이트:** 리퍼럴 파트너가 발행한 전자세금계산서가 홈택스에 정상 수취되었는지 대조.
3. 수취 확인 완료 시 [세금계산서 수취 확인 및 지급 승인] 클릭 -> 상태 `APPROVED` 전이.
4. 등록된 계좌로 수수료 송금 실행.

## 4. 비상 킬스위치(Kill-Switch) 및 긴급 롤백 절차

### 4.1 시스템 즉시 차단 (System Kill-Switch)
긴급 보안 위협, 데이터 오염, 분쟁 다발 시 5초 이내에 플랫폼을 안전하게 동결합니다.
1. Cloudflare Workers 환경 변수에서 `SYSTEM_KILL_SWITCH = "true"` 설정.
2. 또는 터미널에서 다음 명령 실행:
   ```bash
   wrangler secret put SYSTEM_KILL_SWITCH <<< "true"
   ```
3. **작동 결과:** 모든 신규 인입 폼 제출, 오퍼 수락, 슬롯 등록이 즉시 503 점검 중(`MAINTENANCE_MODE`)으로 차단되며, 데이터베이스 쓰기가 100% 동결(Fail-Closed)됩니다. 기존 계약 상태는 안전하게 보존됩니다.

### 4.2 데이터베이스 롤백 (Database Rollback)
비상 상황 발생 시 스키마 및 데이터를 초기 안전 상태로 롤백합니다:
```bash
# 로컬/스테이징 D1 롤백
wrangler d1 execute slotbridge-db --file=./migrations/0001_rollback.sql
```

### 4.3 Git 브랜치 롤백
`feat/slotbridge-kr-mvp` 피처 브랜치는 기존 `main`의 SaaS 비교 사이트와 완전히 물리적으로 격리되어 있으므로, 언제든지 피처 브랜치를 원복하거나 PR을 닫는 것만으로 기존 라이브 사이트에 0.001%의 영향도 주지 않고 복원됩니다.
