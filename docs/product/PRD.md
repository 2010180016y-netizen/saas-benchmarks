# SlotBridge Korea — 제품 요구사항 명세서 (PRD.md)

**문서 버전:** 1.0.0  
**작성일자:** 2026-10-31  
**제품명:** SlotBridge Korea (SBK)  
**제품 비전:** 24~72시간 내 급행 입주·이사청소 고객과 전문 업체의 잔여 유휴 슬롯을 연결하는 무자본·고도 자동화 성과형 B2B2C 매칭 플랫폼  
**작성 주체:** Codex Marketplace Product Manager & Staff Engineer  

---

## 1. 배경 및 해결하려는 문제 (Problem Statement)

1. **소비자 고통:** 이사 2~3일 전 갑작스러운 입주청소 필요 시, 대형 플랫폼(숨고, 미소)은 견적 비교에 24시간 이상 소요되거나 예약이 마감되어 발을 동동 구름.
2. **원 유입업체 고통:** 자사 스케줄이 꽉 차서(오버플로우) 걸려오는 고객 전화/문의의 30~50%를 단순 거절하고 버려야 하며, 고객 응대 비용만 발생하고 수익은 0원임.
3. **작업업체 고통:** 예약 취소 등으로 24~72시간 내 갑자기 펑크 난 빈 일정(잔여 슬롯)이 생겨도, 즉시 일감을 찾을 경로가 없어 인건비와 고정비를 허공에 날림.
4. **솔루션:** 원 유입업체의 버려지는 오버플로우 문의를 웹 위젯을 통해 고객 동의 하에 흡수하여, 관내 빈 일정을 가진 검증된 청소팀에 1:1 배타적으로 즉시 매칭하고 성과 발생 시 8% 수수료를 정산(원 유입사 35% 배분).

## 2. 4대 이해관계자 가치 제안 (Value Proposition)

| 이해관계자 | 획득 가치 (Why They Care) | 핵심 액션 |
|---|---|---|
| **최종 고객** | 발품 팔지 않고 24~72h 이내 출동 가능한 검증된 전문 청소팀 1곳과 즉시 직통 연결 (수수료 0원) | 조건 입력 및 제3자 제공 동의 후 유선 확정 |
| **원 유입업체** | 거절하던 고객 문의를 위젯으로 연결하여, 건당 7,000원(수수료의 35%)의 무자본 순익 창출 | 오버플로우 링크/위젯 안내 |
| **수행 파트너** | 펑크 난 빈 슬롯을 선착순으로 채워 하루 25만 원 매출 회수 (견적비 0원, 완료 시에만 8% 후불) | 가용 슬롯 등록 및 15분 내 오퍼 수락 |
| **플랫폼 운영자** | 서버리스 0원 인프라로 완전 자동화 매칭, 건당 13,000원(Net Take Rate 5.2%) 현금 창출 | 주간 10분 승인 및 월간 세무 처리 |

## 3. 기능 범위 정의 (In-Scope vs Out-of-Scope)

### 3.1 MVP 범위 (In-Scope)
- 서울 관악구·동작구 권역 대상 24~72시간 급행 입주·이사청소 단일 품목 매칭.
- 고객 모바일 웹 인입 폼 (조건 입력, 가격 미확정 고지, 개인정보보호법 제17조 동의, 통신판매중개 고지).
- 고객 1-Click 신청 현황 조회 및 즉시 철회/삭제 URL (`/status?token=...`).
- 원 유입업체용 화이트라벨 웹 위젯 / 리퍼럴 URL (`?ref=PARTNER_ID`).
- 수행 파트너용 모바일 웹 달력 기반 잔여 슬롯 등록 및 1:1 오퍼 수락/거절 (15분 TTL).
- 서비스 완료 증빙(사진 2장) 등록 및 고객 사후 만족도 교차 검증 웹 폼.
- B2B 성과 수수료(8%) 및 리퍼럴(35%) 정산 원장(`ledger_events`, `invoices`) 자동 집계.

### 3.2 [초기 절대 미지원 항목 (Out-of-Scope - Strict Guardrails)]
1. **고객 선결제 및 PG 에스크로:** 결제대금 예치 및 PG 연동 일체 배제 (고객-업체 현장 직거래).
2. **24시간 무조건 출동 보장 / 자동 보증:** 가용 슬롯 미확보 시 거짓 확약 금지 (솔직한 매칭 불가 안내).
3. **자동 견적 확정:** 알고리즘에 의한 가격 확정 금지 (공급업체 유선 상담 후 현장 확정).
4. **가짜 후기 및 리뷰 없는 조작 별점:** 검증되지 않은 평점 표기 전면 금지.
5. **자동 영업 스팸 / 무단 크롤링:** 타 플랫폼 무단 스크래핑 및 스팸 문자 자동 발송 금지.
6. **폐기물 처리 / 포장이사 운송 중개:** 화물자동차 운수사업법 규제 영역 일체 배제.

## 4. 핵심 기능 요구사항 (Functional Requirements)

### FR-01: 고객 인입 및 가용성 조회
- **설명:** 고객이 관악/동작 권역, 희망 일시(24~72h 이내), 주거 형태, 면적을 입력하고 가용성을 조회한다.
- **수용 조건 (AC):**
  - Given: 고객이 유입 경로를 통해 인입 페이지에 접속했을 때
  - When: 필수 항목(시군구/동, 일시, 형태, 면적, 이름, 전화번호)을 입력하고 조회를 누르면
  - Then: 24~72h 범위 밖이거나 타 지역인 경우 즉시 사유를 안내하고, 관내 범위인 경우 "최종 가격은 상담 후 확정되며, 출동 가능 여부를 확인 중입니다"라는 안내와 함께 법정 동의 화면으로 이동해야 한다.

### FR-02: 법정 필수 동의 및 불변 로깅
- **설명:** 개인정보보호법 제15조, 제17조 및 전자상거래법 제20조 제2항 고지를 받고 동의를 수집한다.
- **수용 조건 (AC):**
  - Given: 고객이 신청서 제출 화면에 도달했을 때
  - When: 필수 체크박스 2종을 고객이 직접 체크하고 제출하면
  - Then: 체크박스 기본 상태는 해제(`false`)여야 하며, 제출 시 `consent_events` 테이블에 타임스탬프, IP 해시, User-Agent, 약관 버전이 저장되고 PII는 `AES-256-GCM`으로 암호화되어 저장되어야 한다.

### FR-03: 원 유입업체 위젯 및 리퍼럴 결속
- **설명:** 제휴업체 웹사이트나 문자 링크(`?ref=PARTNER_ID`)를 통해 유입된 고객의 기여도를 추적한다.
- **수용 조건 (AC):**
  - Given: `ref` 파라미터가 포함된 URL로 고객이 인입되었을 때
  - When: 고객이 신청을 완료하면
  - Then: 서버는 유효한 승인 파트너 ID인지 검증하고 `inquiries.attribution_partner_id`에 결속하며, 클라이언트가 임의 변조할 수 없도록 서명 토큰을 적용해야 한다.

### FR-04: 잔여 슬롯 등록 및 동시성 제어
- **설명:** 수행 파트너가 특정 날짜/시간대의 빈 일정을 캘린더에서 등록한다.
- **수용 조건 (AC):**
  - Given: 승인된 수행 파트너가 슬롯 관리 페이지에 접속했을 때
  - When: 24~72h 내 특정 날짜와 시간대(오전/오후)를 선택하여 등록하면
  - Then: 중복 등록을 방지하고 `capacity_slots`에 `AVAILABLE` 상태로 즉시 반영되어야 한다.

### FR-05: 1:1 배타적 오퍼 매칭 엔진
- **설명:** 신규 인입 발생 시 최적의 파트너 1곳을 선정하여 15분 독점 수락 권한을 부여한다.
- **수용 조건 (AC):**
  - Given: 신규 인입이 대기 상태(`PENDING_MATCH`)일 때
  - When: 매칭 엔진이 가용 슬롯 파트너 중 평점 최우선 파트너 1곳을 선정하면
  - Then: `assignment_offers`에 15분 만료시간(TTL)과 함께 오퍼를 생성하고, 타 업체에는 일체 노출되지 않아야 하며, 15분 경과 시 자동 취소 후 차순위 파트너에게 배타적 재전송되어야 한다.

### FR-06: 오퍼 수락 및 고객 직통 연결
- **설명:** 파트너가 15분 내 오퍼를 명시적으로 수락하면 고객 연락처가 1회성으로 복호화 노출된다.
- **수용 조건 (AC):**
  - Given: 유효한 오퍼를 수신한 파트너가
  - When: 15분 이내에 [수락하기]를 클릭하면
  - Then: 슬롯 상태는 `RESERVED`로 원자적(Atomic) 락이 걸리고, 파트너 화면에 고객의 이름, 전화번호가 표시되며 "30분 이내 유선 연락 요망" 안내가 노출되어야 한다.

### FR-07: 시공 완료 보고 및 교차 검증
- **설명:** 청소 완료 후 파트너가 증빙을 제출하고 고객 설문과 대조한다.
- **수용 조건 (AC):**
  - Given: 배정된 매칭 건의 청소가 종료되었을 때
  - When: 파트너가 완료 사진 2장을 등록하고 최종 서비스 대금을 입력하면
  - Then: 상태는 `PENDING_VERIFICATION`이 되고, 고객에게 0원 웹 만족도 링크가 발송되어 고객 확인 완료 시 `FULFILLED`로 확정되어야 한다.

### FR-08: 정산 원장 및 청구서 자동 산출
- **설명:** 완료 확정 건에 대해 플랫폼 수수료 8%와 리퍼럴 배분 35%를 원장에 기록한다.
- **수용 조건 (AC):**
  - Given: 매칭 건이 `FULFILLED` 상태로 전환될 때
  - When: 정산 이벤트가 트리거되면
  - Then: `ledger_events`에 플랫폼 매출(20,000원)과 리퍼럴 비용(7,000원)이 불변 기록되고, 월말 파트너별 청구서(`invoices`)가 자동 생성되어야 한다.

## 5. 비기능 요구사항 (Non-Functional Requirements)

1. **비용 한도 (Zero-Cost Principle):** 월 인프라 비용 $0.00 유지 (Cloudflare Workers/D1 무료 티어 한도 내 운영).
2. **성능:** 모바일 페이지 최초 로드(LCP) 1.2초 이내, API 응답 지연시간(TTFB) p95 < 80ms.
3. **가용성:** Cloudflare 엣지 99.9% 가용성, 장애 발생 시 fail-closed (개인정보 노출 방지).
4. **보안/개인정보:** PII 필드 레벨 AES-256-GCM 암호화, 로그 내 PII 마스킹 100%, 30일 경과 데이터 완전 파기 스케줄러 내장.
