## 1. 공급자 네트워크 핵심 원칙

1. **사전 심사제 (No Unapproved Dispatch):** 관리자(회기님)의 사업자등록증 및 영업배상책임보험 검증을 통과하기 전까지, 파트너는 어떠한 고객 인입 오퍼도 수신할 수 없으며 슬롯 등록도 차단된다.
2. **실측 가용성 원칙 (No Fake Availability):** 공급자가 시스템 캘린더에 직접 날짜와 시간대를 지정하여 등록한 슬롯에 한해서만 '실시간 가능'으로 판정한다. (임의의 가짜 실시간 슬롯 생성 엄격 금지).
3. **타임존 정합성 (Asia/Seoul Standard):** 모든 슬롯 등록 및 매칭 판단은 대한민국 표준시(`Asia/Seoul`)를 기준으로 하며, 24~72시간(익일~+3일) 범위를 벗어난 슬롯은 서버에서 거부된다.
4. **무단 크롤링·스팸 원천 금지 (Safe Acquisition):** 공개된 청소업체 전화번호를 무단으로 긁어 판촉 문자를 발송하는 행위를 전면 금지하며, 오직 자발적 신청 페이지 및 정식 초대 링크를 통해서만 파트너를 확보한다.

## 2. 파트너 상태 머신 (Partner State Machine)

```
[자발적 신청 폼 제출]
        │
        ▼
 PENDING_APPROVAL  ────────(관리자 서류/보험 검증 승인)───────▶  APPROVED (정식 활성)
        │                                                              │
        │ (서류 미비/부적격)                                            │ (클레임 3회/노쇼 적발)
        ▼                                                              ▼
    REJECTED                                                       SUSPENDED
                                                               (가용 슬롯 전원 자동 취소)
```

| 상태값 | 권한 및 제약 | 슬롯 등록 가능 여부 | 매칭 오퍼 수신 여부 |
|---|---|:---:|:---:|
| **PENDING_APPROVAL** | 신청 완료 후 관리자 심사 대기 | **불가 (403)** | **불가 (제외)** |
| **APPROVED** | 정식 승인됨 (사업자/보험 확인) | **가능 (24~72h)** | **가능 (최우선)** |
| **SUSPENDED** | 운영 정지 (품질 미달, 노쇼 등) | **불가 (동결)** | **불가 (전면 차단)** |
| **REJECTED** | 신청 반려 | 불가 | 불가 |

## 3. 잔여 슬롯 및 동시성 락 제어 (Concurrency & Anti-Double-Booking)

### 3.1 슬롯 상태 생애주기
1. `AVAILABLE`: 파트너가 캘린더에 빈 일정을 등록한 상태.
2. `OFFERED`: 신규 인입 건이 매칭되어 파트너에게 15분 독점 오퍼가 발송된 상태. (타 인입에 배정 불가).
3. `RESERVED`: 파트너가 15분 내 [수락하기]를 클릭하여 고객과 예약 확정 대기 상태. (이중 예약 원천 차단).
4. `COMPLETED`: 청소 시공 완료 및 증빙 제출 완료.
5. `CANCELLED`: 파트너가 직접 취소했거나 파트너 정지로 취소된 상태.

### 3.2 Race Condition 방지 메커니즘
- D1 SQLite의 원자적 트랜잭션(`UPDATE capacity_slots SET status = 'RESERVED' WHERE id = ? AND status = 'OFFERED'`)을 통해, 동일 밀리초에 복수의 수락 요청이 유입되더라도 오직 1건만 성공하고 나머지는 `HTTP 409 Conflict`로 즉각 거부된다.

## 4. 파트너 품질 및 페널티 관리 기준

| 관리 지표 | 정상 기준 | 경고/조치 기준 | 최종 제재 |
|---|---|---|---|
| **고객 만족도 평점** | 4.5점 이상 (5점 만점) | 4.0점 미만 시 1차 경고 | 3.5점 미만 시 즉시 파트너십 영구 해지 |
| **오퍼 응답률** | 70% 이상 (15분 내 수락/거절) | 50% 미만 시 슬롯 노출 우선순위 강등 | 반복 시 파트너 일시정지 |
| **A/S 무상 재시공** | 접수 후 24h 이내 처리 | 정당 사유 없이 지연 시 경고 1회 | 재방문 거부 시 수수료 환수 및 14일 정지 |
| **노쇼(No-Show) / 무단취소** | 0건 (무관용) | **1회 적발 즉시 영구 퇴출 (Zero Tolerance)** | **위약벌 10만 원 부과** |
